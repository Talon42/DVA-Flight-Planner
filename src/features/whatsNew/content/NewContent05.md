## VATSIM
 - * Added support for VATSIM availability.
 - * Map can now display online controllers.
 - * Filters now support listing only airports within VATSIM controlled boundaries.
 - * Draft flight reports can be created with "Network" set as "VATSIM.

## Misc
 - * What's new and release notes accessible through **Settings > About**.
 - * Choose Schedule Time or Current UTC when generating Simbrief dispatches.

 ## Bug Fixes
 - * Certain Simbrief aircraft no longer cause flight report submission errors.
 - * Bad logins no longer fail silently and hang the app indefintely. Added more support to detect bad login credentials.
 - * Various performance tweaks and enhancements.
